# 《借命不还》制作记录

## 交付定位

第一集《背面》是小说旁白与人物演绎交替的原创形式样片。不是已购买小说IP，不是发行定稿。剧本、人物和图像已存入本地项目；未使用保存的账号凭据，未宣称已写入应用数据库。

2026-09-18完成首集样片：`output/jie-ming-ep01/final/episode-subtitled.mp4`，46.75秒，756x1344，24fps，1122帧。另有不烧字幕版`episode-clean.mp4`、`episode.srt`、`episode.ass`、`receipt.json`与`technical-checks.json`。

11条选用素材均已生成；额外保留女主对白的废弃第一版。14项脚本/剪辑/真实FFmpeg回归测试通过。全片完整解码通过，音画长度和帧时间间隔检查通过，交付字幕与剧本147个有效文字按叙述次序一致。音频相关性检查未检出实质性的剪辑累积偏移。这些只证明交付正确性，不证明商业可看性。

已逐段查看抽帧与手机尺寸字幕图。尚未获得用户的一倍速观看认可；不同机位下桌面道具的细小位移、角色声线跨镜统一程度、动作自然度仍是后续看片要判断的项目。未将`artisticApproval`或`publicationApproval`改为通过。后台8080本次检查没有运行，所以保存至项目目录不等于应用里已出现项目卡片。

## 叙述和表演

- 同一份沈照第一人称旁白母带，使用本机Qwen3-TTS的Serena预置音色。没有克隆演员。
- 旁白解释前世和她知道的契约规则；对白提出翻纸、试签、找师父等要求。
- 对白的真实发音和视频一起剪，不把另一句配音硬贴到现有嘴形。
- 旁白画面不发送旁白文本给H3，不让H3逐镜创造叙述者。
- 画面按事件组织。开场叙述跨前世和今生切点，递纸动作跨两个旁白句连续保留。

## 图像与模型

定妆与首帧由本次内置imagegen生成，并以相同角色和书房主图作参考。工具没有返回可核实的具体模型版本，不标注为未经确认的gpt-image-2.5。

`output/jie-ming-ep01/keyframes/` 保存主图、人物中近景、雷劫、纸角、递笔、起身和门口图。`doorway-v0.png`是走向错误的废稿，不参与渲染；`doorway.png`改为朝实际房门移动。本目录`portraits/`另存两个角色中近景便于项目导入。

视频沿用官方普通H3 I2V节点和本地pruned INT8 ConvRot模型，20步，Turbo关闭。没有为这次任务改动用户ComfyUI全局启动配置或切换注意力后端。运行环境仍使用其原来的Sage配置，不能将本片称为Sage/SDPA对照试验。

生成画布768x1344，原生24fps。H3本地节点将时间长度向上对齐到`frames % 17 == 5`；实际时长从成品读取。已先生成的148帧请求实际输出158帧，此事实保存在状态中，不改写历史；其余请求使用合法帧数。这个对齐是时长约束，不是流畅度保证。

最终画面左右各裁6像素成为756x1344的9:16，没有用插帧、倍速、慢放或定格补齐旁白。

## 已观察到的问题与处理

1. 雷劫原片后半段恢复站立等待，不符合死亡记忆；舍弃后半段，在雷光阶段切今生，不把坏表演留在成片里。
2. 第一条对白有约2.6秒开口前等待，按真实语音起点裁去，不保留模型无意义的准备时间。
3. 旁白不能逐句变成独立镜头。采用分块声音时间线，多句话共用动作，也允许一句话跨场景剪辑。
4. 前世雷劫时命牌仍在沈照腰间。补明归还实物不能解契，避免与借过命牌的前提相矛盾。
5. 人物设定中删去不存在的第二支笔；定妆照与镜头均只保留一支。
6. 第一版「那你签」又在手中生成一支笔，和已经递笔的镜头冲突；废弃`07-you-sign-v1`，用不露手的近景重拍`07-you-sign-v2`，不覆盖废稿记录。
7. 递笔镜头后半出现伸手接笔趋势，与「没敢接笔」冲突。剪掉后半，在旁白中接入裴衡开口前的无声反应，不让旁白重复定义错误动作。
8. 「翻过来」和回应之间裁去1.5秒非说话区间，回答切轻度收紧的构图；语音和画面成对剪，字幕随最终声音重排。
9. 发现短音频响度处理和封装截断导致的累积音频提前；改用每视频帧2000个48kHz采样的精确长度，并新增真实FFmpeg回归测试。技术检查另外用声波相关性验证剪辑偏移，但不据此宣称模型原生嘴形合格。
10. 「这张纸，我拿去问师父」的ASR把整句当成一个粗时间块，自动拆句后第一句字幕落在真正开口前。新增`timing_review_required`检查，按该片真实语音活动区间显式校正两句字幕；不因识别文字全对就接受错误时间戳。
11. 女主重拍的开头仍有模型自己改变景别、长时间不说话的问题；选用构图已稳定的真实开口段，未把提示词要求当作已实现的证据。

## 可重复运行

在仓库根目录：

```powershell
python scripts/produce-zhouzong-episode.py --output-dir output/jie-ming-ep01 --from-take 01-lightning-v1
.venv-narration/Scripts/python.exe scripts/qa-zhouzong-dialogue.py --output-dir output/jie-ming-ep01 --watch
python scripts/compose-novel-performance.py --output-dir output/jie-ming-ep01
python -m unittest scripts/test_novel_performance.py scripts/test_zhouzong_episode.py
.venv-narration/Scripts/python.exe -m unittest scripts/test_novel_media.py
.venv-narration/Scripts/python.exe scripts/verify-novel-performance.py
```

渲染器保留原名称以兼容已有项目，通过`--output-dir`处理本集；完成的镜头按身份哈希跳过，已提交的任务继续轮询，不重复提交。改变图片、文本、种子或帧数须使用新take ID。

`manifest.json`存正文、模型提示和剪辑次序，`edit-overrides.json`存选用的实际素材范围，`final/receipt.json`存最终时间线和素材哈希。`--through 03-request-v1`只能输出标记为未完成整集的开场预览，不覆盖最终片。

## 发布前仍须验证

H3的24fps容器、ASR转写正确或技术检测通过，都不等于表演、口型、动作、镜头连续性已达到商业标准。需要看一倍速成片，确认旁白口吻、角色声音跨镜一致性、手和道具连续性，以及结尾是否让人愿意看下一集。来源、模型和字体权利与发行手续需按实际发布渠道复核。
