# 前两集联动修订

以下保留第一、二集在联合改稿阶段的制作安排，文中的“尚未生成”描述该阶段，不代表当前状态。2026-09-20两集修订版均已生成，当前交付以 `episode-01-render.json`、`episode-02-render.json` 为准。原版成片、成片对应稿、第二集单独修订v3均不覆盖；本次仍未写入应用数据库。

## 第一集承担的内容

开场直接给出受害结果，以及一个具体疑问：命牌已经归还，为什么她还会被雷劈？回到借牌当天后，让裴衡以熟人求助的方式开口，沈照追问用途。他回避翻纸，她才要求看背面。

“还牌没有解除契约”在本集得到回答。观众不用知道宗门制度和签名顺序，就能明白她为什么拒签。本稿不再把“你写在我名字前头”作为反制手段，避免必须临时解释第一签名者规则才看得懂。原有世界规则并未被改成强抢即可成立。

第一集实际完成拒签与收牌。结尾的障碍是裴衡不许她带走证据，第二集立刻处理这件事，不用重复整段受劫画面。

## 第二集承担的内容

开头用一小段小说旁白补回当前风险，随后直接延续门口交锋。裴衡搬出宗门规矩，还想代问师父；沈照转向值房，让对话有旁人听见。

岑岳承认印由自己所盖。沈照问“雷打谁”，他答“有为师在”，两人并没有回答同一个问题。她要求把保证写下，他暂停签字。这段靠回应的内容表现压力，不靠轮流冷笑或加长沉默。

旧稿里沈照轻易把证据交给师父安排的人，留证成果不够明确。本稿增加她在执事记下一笔之后才松开纸角的动作；这只说明有过公开收存，不能证明整个档案体系安全，也不能保证师父以后不动手脚。第三集仍必须实际查档和核对借牌人的情况。

结尾从自己拒签转向寻找其他借牌者。她只听到还有旧借条，没有理由断言别人已经丧命。

## 声音与表演

- 沈照旁白保留小说叙述口吻。开场讲亲历伤害，中段讲当时的误判，第二集讲对师父的旧信任；不要把每句都读成宣誓。
- 裴衡起初想尽快办完一件熟人之间的小事；被问到用途时用“压阵”搪塞，被点破时追问信息来源，第二集再用制度压人。不同阶段有不同目的，不统一套低沉反派声线。
- 岑岳认为徒弟在小题大做。“有为师在”是要求停止追问，归档是终止当前争执，不故意表演心虚、不把“前几张”念成谜底。
- 对话有必要的铺垫、追问与回避，允许短回答，但不统一限制字数。不能把新增的正常交流重新压成“翻过来”“验印”“写上”。
- 同一集旁白使用一份固定音色母带；在人物交谈时停止，交锋改变局面后继续。声源顺序记录在 `revision.json`，它不是H3提交清单。
- 当前合成器要求原生对白音画同步。对白跨反应镜头的独立音画剪辑尚需实现和验证，不拿静默旧脸配新台词冒充完成。

## 镜头与素材安排

| 场景事件 | 应看到的关键动作 | 制作判断 |
| --- | --- | --- |
| 第一集前世受劫 | 命牌已回到沈照身上，雷光到来后立即切到今生 | 旧受劫原片可作候选；抽取有效动作，不为了等旁白而延长僵持，不保证旧素材能覆盖新声音 |
| 借牌与追问用途 | 借条和笔递近，沈照没有接 | 新对白要重做；参考现有双方定妆和书房首帧，不能只靠两张正面肖像轮换 |
| 揭开背面 | 压纸的手撤开，同一张纸翻面，圆印露出 | 重点补齐可剪的手部动作；画面中的印只用于辨认，不依赖生成可读汉字 |
| 拒签与堵门 | 左手把命牌收入左袖，右手拿纸，走向右门并被挡 | 收牌、拿纸、堵门可分覆盖，但方向和道具状态必须一致；本集不把命牌再挂到腰上 |
| 第二集转向值房 | 门走不通，沈照转左窗，纸一直在她控制下 | 沿用同一房间，不机械拿门口尾帧当窗边新角度首帧；优先按参考重建空间一致的首帧 |
| 师父认印与回避担责 | 看印、对答、纸边放笔、没有接笔 | 新对白与自然倾听覆盖重拍；不要用一只不动的手撑满整段旁白 |
| 公开收存 | 纸未签，执事记下一笔，沈照松手，原件入夹 | “记一笔”和“松手”是新素材需求；旧归档原片只能作参考，不能声称已经拍到新动作 |

旁白一段可以横跨主镜头、手部与对方反应；连续动作也可以承接几句旁白。所有素材都按实际声音和动作入出点剪，不用静帧、循环、无依据变速或插帧掩盖素材缺口。沿用原生24fps、统一白色字幕与手机安全区；新字幕必须重新对齐新声音。

## 两集连接与后续

第一集末与第二集初的状态完全一致，见 `revision.json`：白天、书房右门、命牌在沈照左袖内袋、未签借条折好在右手、裴衡堵门。第二集不重新展示命牌在桌上，也不把拿纸的手换掉。

第二集结尾只推进到值房收存。第三集从次日的登记簿和旧借条查起，再引入陆闻溪；不跳成已经掌握全宗门罪证，也不在下一集凭空拿回原件。

第三至十二集继续沿用开发大纲的调查、解契和追责主线，本次没有重写整季。新稿不再用第一集的签名次序测试，后续不得当作已经演给观众看的信息来引用。

## 交付边界

当前第一集发声文字257字，其中旁白126字；第二集287字，其中旁白111字。按每秒4至4.5字粗算，仅说话分别约57至64秒、64至72秒，尚未包含换气、交谈间隙和不可与声音重叠的动作。制作预算暂留第一集约65至85秒、第二集约75至95秒，必须等实际声音确认，不把所有停顿删除或把配音加速来满足这个区间。

本轮先固定两集能读懂的故事和可执行的制作需求，未开始新一轮长视频渲染。字数统计与按说话速度计算的时长只用于暴露预算问题，不能充当实际朗读时长或艺术验收。

第一集应在投入整集重拍前核对三件事：开场是否能听懂受害关系；正常速度下借牌的交谈是否像熟人交流；翻纸到收牌的动作是否连贯。技术检查不能替代用户观看，也不以频繁自评分拖延制作。
